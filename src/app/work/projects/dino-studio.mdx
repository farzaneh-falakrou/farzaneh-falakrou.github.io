## Overview

Dino Studio is an interactive single-page application built during a 6-week Chingu Voyage sprint. I was the sole designer working alongside four developers and a voyage guide, collaborating asynchronously in a real team environment with structured sprints and a shared GitHub workflow.

The product uses data from the Natural History Museum to help users explore dinosaurs through search, data visualisations, and a detailed species view. Two design challenges defined the project: first, the taxonomy tree — the full evolutionary classification was far too deep to render usably, so I simplified it to show only contextually relevant branches. Second, the location data — individual country markers overlapped badly on the map, so I switched to a choropleth visualisation showing dinosaur density per country, paired with a scrolling carousel for selection.

I used Google Looker Studio to prototype the data visualisations before committing to the Figma designs, which sped up iteration significantly. The design was validated through two rounds of usability testing, each with 5 participants, with MoSCoW prioritisation used to triage fixes between rounds. The result is a one-page dashboard that works for both children and adults without feeling like it was designed for either specifically.
