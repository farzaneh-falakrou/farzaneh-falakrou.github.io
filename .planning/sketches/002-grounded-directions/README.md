# Sketch 002: Grounded Design Directions

## Design Question
Sketch 001 was generic. This one anchors each direction to a real established design lineage so the choice becomes "which design tradition do I align with?" rather than "which colors do I like?"

## How to View
Open `.planning/sketches/002-grounded-directions/index.html` in a browser.

## Variants

### A · Design Engineer
**Lineage:** Rauno Freiberg (Vercel) · Brian Lovin (Notion) · Linear · Vercel docs
**Visual language:** Near-black surface (#0a0a0b), Inter Tight + Geist Mono, sidebar nav like a real app, keyboard shortcuts (⌘K), status indicators, monospace metadata. Layout feels like a tool, not a marketing page.
**Says:** "I think like a product engineer. The interface IS the work."
**Best for:** Roles at developer-tool, design-system, or technical SaaS companies (Linear, Vercel, Notion, Stripe, GitHub).

### B · Editorial
**Lineage:** Frank Chimero · Pentagram · NYT Magazine · It's Nice That
**Visual language:** Warm paper (#f5efe6) like newsprint, Fraunces serif with terracotta accent (#b34a2a), drop caps, vol/issue numbering, projects presented as essays with titles like articles. Drops "magazine masthead" structure.
**Says:** "I think rigorously. The work has narrative weight, like an essay."
**Best for:** Roles where written communication and process thinking matter — design leadership, research-heavy roles, agencies that value writing.

### C · Swiss Modern
**Lineage:** Müller-Brockmann · Karri Saarinen (Linear founder) · Aristide Benoist · Akzidenz-Grotesk tradition
**Visual language:** Pure white background, 12-column mathematical grid (toggleable overlay), Inter as Akzidenz substitute, single hot accent (vermillion red #c00). Project listing as table. Metadata in left rail like a museum label. Confident in its restraint.
**Says:** "My thinking IS the visual language. No decoration needed."
**Best for:** Roles where craft discipline and information architecture are core (design systems leads, IDE/tool designers, finance/banking products).

### D · Signature
**Lineage:** Tobias van Schneider · Jason Yuan · Mathieu Comoy · contemporary studio sites
**Visual language:** Warm cream (#ebe8e2), Instrument Serif for big italic display moments, single bold orange (#ff5a36) accent, pill-shaped nav, animated marquee, rounded project cards with hover state inversion. Personality forward.
**Says:** "I have a strong point of view. Take it or leave it."
**Best for:** Creative-led product companies, brand-forward startups, freelance work, agencies that value personality.

## What to Look For

Each variant is engineered to communicate a different positioning:

| | A: Engineer | B: Editorial | C: Swiss | D: Signature |
|--|---|---|---|---|
| **Tone** | Precise, app-grade | Considered, written | Disciplined, restrained | Confident, personal |
| **Reads as** | Junior-staff IC | Senior-thoughtful | Design-systems-craft | Individual contributor with strong taste |
| **Risk if mis-fit** | Cold / corporate | Too academic | Too austere | Too "look at me" |
| **Strongest for** | Tool companies | Research-heavy | Systems-focused | Brand-forward |

Things to actually evaluate:
- Which feels like *you* opening your mouth?
- Which would you be proud to send to a hiring manager at Linear vs. Apple vs. Figma vs. an agency?
- Which can you maintain — both visually and tonally — as you add 8+ more case studies?
- Does the project-listing format match how you want people to enter the case studies?
