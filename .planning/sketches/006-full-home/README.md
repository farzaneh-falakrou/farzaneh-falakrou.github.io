# Sketch 006: Full Home Page (Stitched)

## Purpose
Combine all locked decisions into one cohesive scrollable home page to verify the rhythm works end-to-end before moving to GSD intake & build.

## Sections (in order)
1. **Brand mark** (top-left, sticky, flips color on dark sections)
2. **Floating dock** (bottom-center, hides on scroll-down, tracks active section)
3. **Hero** — eyebrow with pulse dot, oversized italic headline, two-column sub with bio + meta
4. **Marquee** — skills strip on dark background, infinite scroll
5. **Selected work** — 4 asymmetric zig-zag rows with preview, italic name, italic description, tags, stats, CTA
6. **About teaser** — left: big italic headline + bio + "More about me →" / right: career/tools/awards sidebar
7. **Contact CTA** — dark section, big italic question, email button, alt social links
8. **Footer** — dark, 4-column grid (brand, index, elsewhere, contact) + meta bar

## How to View
Open `.planning/sketches/006-full-home/index.html` in a browser. Scroll the entire page.

## What's Live
- Floating dock hides on scroll-down, reveals on scroll-up
- Dock anchor links scroll smoothly to each section
- Dock highlights active section as you scroll
- Brand mark inverts color when over dark sections (contact / footer)
- Project cards alternate left/right (asymmetric zig-zag)
- Hover states on all interactive elements

## What to Verify
- Rhythm: does the page feel paced or does it drag/rush?
- Voice consistency: does every section sound like the same person?
- Visual continuity: does it feel like one design, not stitched pieces?
- Each section has a purpose; none feel orphaned

## Decisions Confirmed in This Sketch
- Marquee transition between hero and work feels right (dark break)
- About teaser is enough — full About lives on a separate page
- Contact section preceding footer is correct (CTA first, then chrome)
- Footer columns: Index · Elsewhere · Contact (4-col with brand)
