# Sketch 001: Aesthetic Direction

## Design Question
What visual language should define the portfolio? This is a UI/UX portfolio — the site itself is a design argument.

## How to View
Open `.planning/sketches/001-aesthetic-direction/index.html` in a browser.

## Variants
- **A: Editorial** — Cormorant Garamond + DM Sans. White, structured, magazine-grade. Type does the heavy lifting. Numbered project list.
- **B: Dark & Refined** — Space Grotesk + Inter. Near-black, precise, tool-like. Card grid with subtle borders.
- **C: Warm & Human** — Fraunces + DM Sans. Cream palette, organic rounded cards, approachable but sophisticated.
- **D: Bold / Expressive** — Cormorant + Space Grotesk. Split dark/light hero, terracotta accent strip, project list format.

## What to Look For
- Does the first impression communicate "thinks deeply AND has strong taste"?
- Which typography feels like your voice?
- Does the project listing format feel right (numbered list vs cards vs linked rows)?
- Which color palette feels like you?
