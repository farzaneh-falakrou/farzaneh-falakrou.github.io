    Inside the component, add:
    - `const [hidden, setHidden] = useState(false);` — controls the `.hidden` class on the nav.
    - `const [active, setActive] = useState<string>("hero");` — current active section id.
    - `const lastY = useRef(0);` — tracks previous scrollY for direction detection.

    Behavior 1 (hide on scroll-down, reveal on scroll-up) — one `useEffect` with empty deps:
    Attach a `scroll` listener with `{ passive: true }` to `window`. On each call, read `const y = window.scrollY;`. If `y > lastY.current && y > 200` set `setHidden(true)`. Else `setHidden(false)`. Then `lastY.current = y`. Return a cleanup that removes the listener.

    Behavior 2 (active section tracking) — second `useEffect` with empty deps:
    Create `const observer = new IntersectionObserver((entries) => { const visible = entries.filter((e) => e.isIntersecting).sort((a, b) => b.intersectionRatio - a.intersectionRatio)[0]; if (visible) setActive(visible.target.id); }, { rootMargin: "-33% 0px -33% 0px", threshold: [0, 0.25, 0.5, 0.75, 1] });`. Loop over `SECTIONS`, do `document.getElementById(id)` and if truthy `observer.observe(el)`. Return a cleanup that calls `observer.disconnect()`.

    Behavior 3 (smooth scroll on click) — define a handler factory: `const onClick = (id: string) => (e: React.MouseEvent) => { e.preventDefault(); document.getElementById(id)?.scrollIntoView({ behavior: "smooth" }); };`.

    JSX: render `<nav className={`${styles.dock} ${hidden ? styles.hidden : ""}`}>`. Map over `SECTIONS` — for each id, render `<a key={id} href={`#${id}`} onClick={onClick(id)} className={active === id ? styles.active : ""}>{id === "hero" ? "Home" : id.charAt(0).toUpperCase() + id.slice(1)}</a>`. After the map, render `<div className={styles.sep} />` then `<a href="#contact" onClick={onClick("contact")} className={styles.cta}>Get in touch ↗</a>`.

    Confirm the CSS module already has all required classes: `dock`, `hidden`, `active`, `sep`, `cta`. (PLAN 02 Task 3 lifted them; nothing should need to be added here.) If `active` is missing from the CSS module (because the sketch's selector is `.dock a.active`, which might have been transcribed as a nested form), normalize it to a standalone `.active` class so `styles.active` resolves.

    React 19 strict mode runs effects twice in development; the explicit cleanups (remove listener, disconnect observer) handle this correctly. No additional guards needed.

    Do not import or use any third-party scroll library. Do not import `framer-motion` or similar. The motion is a pure CSS transition on `transform` (already in the module per PLAN 02 Task 3, lifted from sketch line 73).
